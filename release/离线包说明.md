# 容器镜像离线包（ai-bid-agent-images.tar.gz，约 590MB）

内含两个镜像：`deploy-app:latest`（后端，含 playwright＋Chromium，2026-11-28 / v1.3.1 版，含详情页正文抽取与中性提示分级）与 `nginx:alpine`（前端托管）。
用于无外网/弱网环境演示：整包拷过去，load 完直接起，不需要 pip、npm、浏览器下载。

## 恢复步骤

1. 解压（gzip）：
   `7z x ai-bid-agent-images.tar.gz`，或 Linux 上 `gunzip ai-bid-agent-images.tar.gz`
2. 导入镜像：
   `docker load -i ai-bid-agent-images.tar`
3. 起服务（在项目根目录，代码与 config/ 就位的前提下）：
   `docker compose -f deploy/docker-compose.yml up -d`
4. 验证：
   浏览器开 `http://127.0.0.1/`，或 `curl http://127.0.0.1/api/health`

## 注意

- deploy-app 镜像约 2.08GB（含 Chromium），load 后磁盘占用以此为准。
- 密钥（config/secrets.yaml）不烤进镜像，按仓库 README 部署节单独放置。
- 镜像版本对应 git tag v1.3.1；重新出包前先 `docker compose -f deploy/docker-compose.yml up -d --build app`，并用 `/api/health` 确认 `version` 与源码一致（`docker save` 只认本地镜像，不认源码）。出包命令：
  `docker save -o release/ai-bid-agent-images.tar deploy-app:latest nginx:alpine`
  再 `7z a -tgzip ai-bid-agent-images.tar.gz ai-bid-agent-images.tar`
